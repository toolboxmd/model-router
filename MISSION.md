# Mission

Model Router makes delegation practical for software work. It gives the
human-facing model one versioned policy and one durable runner that route
each authorized task to the most suitable eligible model within subscription
allowances, move it when capacity fails, and return the target project's own
proof. Claude Code is the human-facing host, Codex dispatches and reviews,
and OpenCode runs the workers. AgentsMD and the target project keep workflow,
authority, and proof. Routing improves through evidence from real work,
recorded for Agent Observer.
