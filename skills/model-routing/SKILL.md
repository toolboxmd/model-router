# Model routing

The coordinator selects worker models. Project instructions own delegation,
authority, proof, review, and delivery. Keep their small-direct-work exception;
do not change the human-facing model or override explicit user choices.

For Codex, read [the routing policy](references/codex.md), relative to this
Skill. Reuse it while unchanged. Other hosts are outside v1.

Use the project's existing brief and handoff. Assigned workers do their work;
they do not route it again. Keep review independent from its author.

In the existing handoff, identify the policy version, selected model and effort,
and any override or escalation reason. Distinguish requested from observed
execution. Reuse the existing proof, elapsed time, rework, and usage evidence;
leave unavailable measurements unknown. Instructions guide behavior, not enforce it.
